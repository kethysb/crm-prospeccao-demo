# CRM de prospecção

Demo de um pipeline comercial com contatos fictícios. Inspirada em rotinas de acompanhamento de propostas e agendamento de retornos.

Abra `index.html` no navegador. Cadastre uma oportunidade, selecione sua etapa e informe a data de retorno. Use o filtro para revisar retornos vencidos ou previstos para hoje. O botão de excluir remove a oportunidade da lista.

A aplicação usa HTML, CSS e JavaScript nativo. As alterações ficam no armazenamento local do navegador. O painel funciona offline e não envia mensagens nem usa serviços externos.
